# UE5 Learning Hub v3.39.2 — Editorial Correction Pass

## Purpose
A small student-facing copy correction pass after the v3.39.1 evidence rebuild. No feature expansion and no database change.

## Changed
- Rebuilt the three primary **Environment Art & Set Dressing** case studies around environment-art jobs rather than broad world/traversal design:
  - Dead Space — functional dressing and a lived-in workplace
  - The Last of Us Part II — character storytelling through rooms and props
  - Control — architectural rules, repetition and deliberate disruption
- Rebuilt the three primary **Materials & Surfaces** case studies around actual material-production decisions:
  - Horizon Forbidden West — procedural machine texturing
  - Cyberpunk 2077 — shared layered material library at city scale
  - God of War Ragnarök — reusable materials carrying a sculpted art style
- Replaced the off-topic Hades art/music materials deep dive with Miro Vesterinen's **CONTROL environment and material creation** breakdown.
- Changed the repeated Core Unreal heading `Where do I find/use <lesson>?` to the clearer `Where to find it in Unreal`.
- Removed student-facing development-history copy from Practical Applications, Module 0, Challenge Board and Revision.
- Changed visible project navigation/copy from `Assessment` language to `Projects & progress` / `Projects & community` / `Course / unit` where appropriate. The existing lightweight project evidence/feedback system is unchanged and still does not replace formal college assessment/submission systems.
- Broadened the global search placeholder beyond Unreal-only mechanics/nodes.
