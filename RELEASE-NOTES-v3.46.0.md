# v3.46.0 — Learning Flow Pass

This release adds **no new learning content**. It makes the existing Hub easier to understand and use.

## Student journey
- Home keeps the three clear intentions: **Class Focus / Continue Your Work / Find & Explore**.
- Personal work is no longer replaced by support detours such as Building Blocks, Resources, Revision or Critique.
- Home shows four main learning destinations first; Sculpt and News/Industry sit behind a small **More areas** reveal.
- The bulky Player Card is removed from the Home flow. XP remains in the top bar and full badges/progress remain one click away.
- Fast Support now says what each tool is *for* rather than only naming the section.

## Guided Paths
- Long paths now default to **RIGHT NOW → NEXT WHEN READY**.
- Completed stages are collapsed behind **Show completed**.
- Later future stages are collapsed behind **Show full path**.
- A **SESSION TARGET** reminds students to make, test and prove the current step before treating the route like a checklist.
- Nothing is locked or deleted; every stage can still be revealed.

## Orientation / wayfinding
Key listing pages now explain:
- **USE THIS WHEN**
- **START HERE**
- **THEN**

Support pages also show **Back to your work** when a student temporarily leaves their chosen task to look something up.

## Search
Global search results are grouped into:
- **LEARN**
- **MAKE**
- **FIX / CHECK**
- **REFERENCE**

The group containing the strongest original search hit remains first, so grouping does not throw away the core relevance order.

## Class Focus teacher controls
The existing Class Focus database is reused; no new migration is required.

Teacher → Classes now adds fast controls:
- **Repeat current**
- **Hold current**
- **Next now**
- **Finish now**
- **Copy current to another class**

The schedule is grouped by teaching date for a quicker week-at-a-glance scan.

## Safety
This remains an additive presentation layer. It does not replace:
- app.js
- backend.js
- roster-controls.js
- Prison Cell / Prison Escape
- Blueprint Foundations
- Advanced Blueprint tutorials
- XP/progress data
- Critique / class membership backend

The v3.45.0 Class Focus migration was already applied to the live Supabase project and is included here only as a schema record.
