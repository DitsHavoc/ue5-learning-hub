# Designer Studio Deep Dives — v3.35.1

## Teaching rule

Industry sources are not passive enrichment. Every source must answer three questions for the student:

1. **Why this matters** — what design problem this source helps explain.
2. **Watch / read for** — what decision, constraint or trade-off to identify.
3. **Do something with it** — what the student must test, sketch, compare or change afterwards.

## Source policy

- Prefer first-party developer/publisher material, named-developer talks and strong specialist interviews.
- Noclip is used where its documentary access captures developers explaining the actual production/design process.
- Real-game/design theory references are broader than the Unreal technical imagery policy. Epic documentation remains the source of truth for current UE5 controls and workflow.
- Do not use a video/article simply because the game is famous; it must teach the module's design problem.
