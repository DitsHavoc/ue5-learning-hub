# Unreal Learning Path — v3.32

## The student-facing model

**Building Blocks → Core Systems → Quick Tutorials → Challenges / Projects**

### Building Blocks
Answer: **“What is this thing Unreal keeps mentioning?”**

Target time: 3–9 minutes.  
Structure: **What is it? → Use it when → Do it once → Check you get it.**

Only Core blocks are recommended early. Common and Later blocks are just-in-time references.

### Core System Lessons
Answer: **“How does this system actually work and why?”**

These retain the full lesson structure, practice builds, deeper explanation, debugging and evidence.

### Quick Tutorials
Answer: **“How do I build this mechanic right now?”**

The guide remains straight-through and prescriptive. A small **You're about to use** strip links unfamiliar terminology back to Building Blocks.

### Challenges / Projects
Answer: **“Can I combine and adapt this without being told every node?”**

This is where scaffold fade becomes independence.

## Anti-overload rules

1. Never tell students to complete all Building Blocks before tutorials.
2. Default the Building Blocks library to **CORE only**.
3. Common concepts appear when a tutorial needs them.
4. Later concepts remain searchable but visually de-emphasised.
5. Do not re-teach the complete concept inside every mechanic tutorial.
6. A Building Block should teach one idea, one tiny practice, one observable check.
7. Core Lessons may go deeper; Quick Tutorials stay task-focused.
8. If a new term repeatedly appears in tutorials and students cannot reasonably infer it, add or improve its Building Block rather than bloating every tutorial.
