UE5 Learning Hub v3.42.4 — Visual Trial

Purpose:
A light-touch visual pass to make the Hub feel less like a generic rounded-card / Material / AI-generated dashboard and more like a purposeful games-development learning tool.

This trial changes presentation only:
- flatter surfaces
- smaller corner radii
- less glow and gradient
- stronger edge/line hierarchy
- colour used as an area identifier rather than a full-card effect
- more tool-like sidebar, top bar and buttons

It DOES NOT change:
- app.js
- backend.js
- Supabase
- routes
- Guided Paths
- Game Design Theory
- classes
- leaderboard logic
- XP
- student roster controls
- teaching content

To revert: remove the visual-refresh.css link from index.html or delete the file.
