# UE5 Learning Hub v3.52.0 — Unreal Designer

**Build date:** 11 September 2026  
**Database migration:** No  
**Backend change:** No

## Purpose
Adds the missing application layer between **Designer Studio** and **Unreal Learning**.

- **Designer Studio** = understand the design decision.
- **Unreal Learning** = learn the engine/system.
- **Unreal Designer** = combine the two in a playable build, test it, improve it and capture evidence.

## New area
A new `#/unreal-designer` dashboard contains eight live application tracks:

1. Level Design
2. Environment & Set Dressing
3. Materials & Surfaces
4. Lighting & Atmosphere
5. Landscape & World Building
6. Cinematics & Sequencer
7. Audio & Sound Design
8. Polish & Optimisation

Each track reuses the existing Designer Studio module, its existing Unreal recipes, its existing Studio Build and its existing Revision topic. No duplicate progress model was created.

## Long-form Master Guides
- Landscape Master Guide remains in Unreal Learning and is linked into the Landscape application track.
- Sequencer Master Guide remains in Unreal Learning and is linked into the Cinematics application track.
- Their end-of-guide CTA now goes to the relevant Unreal Designer application track.

## Designer Studio bridge
Every Designer Studio discipline now contains a visible **Apply it in Unreal** bridge. The old one-off Landscape/Sequencer-only bridge has been generalised across all eight disciplines.

## Practical tutorial navigation
Designer-owned practical recipes now breadcrumb/highlight through **Unreal Designer**, while remaining discoverable in Quick Tutorials and global search.

## Future growth
The Unreal Designer dashboard includes explicitly labelled expansion tracks rather than creating orphan pages:
- VFX & Niagara — starter recipes already live.
- UI / UX — starter recipes already live.
- Game Feel & Feedback — starter recipes already live.
- Procedural / PCG Worlds — starter recipe already live.
- Animation & Character Motion — planned.

These are not presented as completed curricula. They become full tracks only when theory + technical learning + applied brief + evidence loop are ready.

## Homework
Adds **Unreal Designer — Apply the Theory** to Guided Homework Paths using the same:

**LEARN → DO → CHECK → BRING BACK**

pattern as the existing structured homework.
