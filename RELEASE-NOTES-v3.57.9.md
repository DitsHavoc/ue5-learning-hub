# UE5 Learning Hub v3.57.9 — Hero Prop Studio Checkpoints

## What changed
- Reworked the Level 4 **Hero Prop** route so it no longer reads like a beginner click-by-click 3ds Max tutorial.
- Kept the same depth of teaching, but changed the modelling stages to a Level 4 studio format:
  - **MAKE**
  - **FOCUS ON**
  - **QUALITY CHECK**
  - **EVIDENCE TO KEEP**
  - **IF IT IS NOT WORKING**
- Added **TECHNICAL SETTINGS THAT MATTER** only where settings genuinely affect the pipeline, such as real-world scale, UVs, Painter baking and Unreal texture interpretation.
- Reduced the project to 11 meaningful production checkpoints from object choice through final portfolio breakdown.
- Kept optional high-poly / LOD / alternate-condition work as stretch only.

## Teaching intent
Students should make their own modelling decisions and demonstrate judgement. The Hub tells them what a strong outcome needs to prove, rather than which 3ds Max button to press.
