# v3.41.2 — Theory Case Study Diversity Pass

**31 August 2026**

Game Design Theory keeps the same 24 lesson IDs, XP, quizzes, practical tasks and Guided Path connections, but every lesson now teaches through a **different game case study**.

## Why this pass exists

The v3.40.0 Theory Hub had strong explanations and professional reading, but its real-game examples leaned repeatedly on a small set of titles such as INSIDE, CONTROL, Elden Ring, Horizon and Death Stranding. That made the theory feel narrower than the design principles actually are.

v3.41.2 broadens the reference library without changing the learning model.
