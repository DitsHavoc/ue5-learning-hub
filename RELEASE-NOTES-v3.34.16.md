- Added a dedicated **Blueprint Snippet Bank** inside Unreal Learning.
- Added 9 curated official Epic UE5.8 source cards covering:
  - key pickup and reusable key setup;
  - locked doors and matching-key checks;
  - player HUD / inventory display;

- Added Snippet Bank results to the global Hub search.
- Added a Snippet Bank shortcut to the Unreal Learning sidebar.
- Quick Tutorials that overlap an Epic snippet now show an **Official Epic Clipboard Assist** block before the build steps.
- Added Snippet Bank calls-to-action to Unreal Learning and Quick Tutorials.

## Source / reuse rule

The Hub does **not** mirror Epic's raw Blueprint clipboard blocks. Students open the official Epic page, use **Copy Full Snippet** there, paste into the named graph/viewport, make the reconnections Epic identifies, then test and study the result.

This keeps the official source authoritative and avoids storing large copied documentation/code blocks inside the Hub.

## Version policy

- Technical source of truth remains current UE5.8 documentation.
- Official Epic imagery / learning references from UE5.6, UE5.7 and UE5.8 remain acceptable when materially accurate.
- The first Snippet Bank release uses current UE5.8 Epic documentation sources.
