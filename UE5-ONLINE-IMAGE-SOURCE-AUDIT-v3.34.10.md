# UE5 Learning Hub v3.34.10 — Online Image Source Audit

## What this pass did

- Searched current **Unreal Engine 5.8** documentation first and only attached screenshots to numbered steps when the visual genuinely demonstrates the instruction.
- Reused exact official visuals already present elsewhere in the Hub instead of asking for duplicate classroom captures.
- Removed misleading repeated Design Studio step images where a licensed-book figure was being reused beside unrelated instructions.
- Kept proof/test/reflection steps image-free when a screenshot would add no useful instruction.
- Did **not** copy third-party tutorial screenshots into the Hub where redistribution permission was not clear. Third-party sources remain reference material for recreating an exact classroom capture.
