# UE5 Learning Hub v3.48.0 — Light Workspace

## What changed
The Hub now uses a dark navigation sidebar with a light grey/white working area.

Palette:
- light neutral workspace
- white lesson/content surfaces
- charcoal text
- Unreal-style blue for actions and navigation
- restrained green / amber / red for status only
- dark sidebar retained for the Games / Unreal identity

## Why
The previous all-dark presentation still shared visual cues with modern AI / tech dashboards. This pass moves the Hub closer to professional learning platforms, documentation sites and productivity software without changing its structure.

## What did NOT change
- learning content
- Class Focus
- signup logic
- progress / XP
- Supabase
- app.js
- backend.js
- roster controls
- existing v3.47 classroom identity work

This is an additive colour skin and is easy to roll back by removing `light-workspace.css`.
