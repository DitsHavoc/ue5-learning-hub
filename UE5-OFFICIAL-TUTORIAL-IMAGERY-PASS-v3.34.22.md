## Policy correction

The old audit asked, “Do we have an image with the exact Hub values?”

The new audit asks, “Does the student need a bespoke image to understand this step?”

If Epic shows the correct current control, node topology or workflow, the Hub reuses that image and writes its own exact value beside it. This is both more accurate to the source material and more sustainable for teaching.
