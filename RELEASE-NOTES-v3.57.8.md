# UE5 Learning Hub v3.57.8 — Hero Prop Deep Guide

Built cumulatively from v3.57.7.

## Changed
- Rebuilt the Level 4 **Hero Prop** pathway as **Hero Prop — Build One Real Object for a Game**.
- Tightened scope so students choose one finishable real-world object rather than an open-ended “make a prop” brief.
- Added GOOD FIT / TOO SIMPLE / TOO BIG guidance and six starter prop directions.
- Added 11 clear project rules, including real-world scale, primary/secondary/tertiary form order, checker-before-Painter and Unreal-as-final-check.
- Added direct links back into the Hub's existing Topology, UV, Substance Painter handoff and UE5 export lessons.
- Added professional/game reference links for material and prop study.
- Replaced the old 8 short stages with **12 fully guided stages** containing **172 numbered actions**.
- The new workflow is: choose scope → reference + dimensions → 3ds Max setup → primary blockout → secondary forms → topology/shading check → UV + checker → Painter import + mesh-map bake → PBR materials + logical wear → Unreal packed material setup → engine verification → portfolio breakdown.
- Added explicit 3ds Max menu paths, naming/save conventions, Substance Painter setup, Unreal ORM channel connections and quality gates.
- Kept separate high-to-low baking as an optional advanced stretch so the core brief remains finishable in 1–2 weeks.
- Version/cache badge bumped to v3.57.8.
