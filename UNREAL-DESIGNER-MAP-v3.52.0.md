# Unreal Designer — content architecture

## Student mental model

**Designer Studio** → What makes this good? What problem am I solving?  
**Unreal Learning** → How does the engine/tool/system work?  
**Unreal Designer** → Can I combine those ideas into playable evidence?  
**Revision** → Can I still make the judgement without the tutorial open?

## Required rhythm for substantial future content

**UNDERSTAND → BUILD → TEST → PROVE**

A new substantial Unreal workflow should have:

1. a theory/design home;
2. a verified technical workflow or focused recipe;
3. an independent application challenge;
4. a test/revision/evidence route.

If it only has item 2, it stays a Quick Tutorial until the rest is ready.
