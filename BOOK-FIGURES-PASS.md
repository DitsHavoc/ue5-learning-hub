# UE5 Learning Hub v3.19.2 — Book Figures + Visual Flow Pass

This pass integrates selected educational figures from **Unreal Engine 5 Best Practices (2025)** into the Designer Studio without turning pages into image dumps.

## Visual flow
1. Learn the transferable design principle.
2. Study a finished-game / current Unreal reference.
3. Complete the Play / Watch / Analyse prompts.
4. See selected licensed book figures that reinforce the principle.
5. Check current UE5.8 engine context and production habits.
6. Follow practical Quick Tutorials.
7. Complete the Studio Build and critique the result.

## Added
- 18 selected book visuals stored locally as compressed WebP assets.
- Dedicated **Licensed Book Visuals** presentation blocks, visually distinct from game references and Epic screenshots.
- Book-figure labels/source notes and the existing click-to-enlarge viewer.
- Book visuals added to all eight Designer disciplines.
- Extra figures added to the most relevant Quick Tutorials, including fog, Lumen, set dressing, UV/materials, Sequencer/audio and profiling.
- Visual grids adjust to the number of figures so 1, 2, 3 and 4-image groups do not leave awkward empty columns.

## Educational-use note
- Teaching text remains original Hub material and paraphrases/rebuilds ideas for students.
- Selected figures/page crops are included under the college's licensed educational use.
- The book is UE5.4-era; current Epic UE5.8 documentation remains the technical source of truth when UI or behaviour differs.
