# UE5 Learning Hub v3.41.3 — Theory Case Study Parity + Watch It In Action

## Why this pass exists

v3.41.2 solved repeated games by giving all 24 Game Design Theory lessons a different case study. v3.41.3 makes the depth consistent too: OMORI and Jet Set Radio are no longer unusually rich outliers. Every lesson now treats its chosen game as something to analyse, watch and question rather than simply name.

## Theory case-study standard

Every one of the 24 lessons now includes:

- one unique named game case study;
- a bespoke case-study introduction;
- three concrete observations tied to the lesson principle;
- one designer question that asks students to infer or transfer the principle;
- at least three written professional, developer, official or research sources;
- one WATCH IT IN ACTION resource selected because motion, presentation or developer explanation helps teach the principle;
- the existing practical task, scenario quiz, XP and Apply It bridge.

## Watch It In Action

Fifteen lessons use a direct YouTube source that can play inside the Hub. The iframe is created only after the student presses **Play here**, using `youtube-nocookie.com`. There is no autoplay and no YouTube thumbnail request on lesson load.

Nine lessons use the strongest official/developer/professional video or media page rather than forcing a weaker embeddable clip. Those open in a new tab.

Each watch resource includes a **WATCH FOR** prompt and an **AFTER WATCHING** question so the video remains an analysis task rather than passive viewing.
