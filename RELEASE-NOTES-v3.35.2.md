# UE5 Learning Hub v3.35.2 — Game Diversity + Resource Library

## Why this release exists

Designer Studio had 24 case-study slots but only seven different games, so otherwise strong design principles began to feel repetitive. At the same time, the Hub's useful free-assets, sound and professional-reference links were buried at the bottom of the Designer landing page.

v3.35.2 fixes both problems without changing student progress or assessment data.

## 24 different games in the LOOK layer

The three case studies in each of the eight Designer disciplines now use a different shipped game. The LOOK layer therefore contains:

- **24 case studies**
- **24 distinct games**
- **0 repeated games**

The spread now ranges from Portal 2, Viewfinder and Dishonored 2 through Firewatch, Stray, Teardown, Alan Wake 2, LIMBO, Subnautica, Jusant, Journey, Outer Wilds, Hi-Fi RUSH and Ori and the Will of the Wisps.

Professional deep dives can still revisit a title when an interview, documentary or postmortem is especially valuable; only the top case-study layer enforces one-game-per-slot.

## New Resource Library

The former bottom-of-Designer resource strip is now a dedicated **🧰 Resource Library** at `#/resources`.

It is reachable from:

- the Reference section of the sidebar;
- a large Home-page landing card;
- a prominent bridge near the top of Designer Studio;
- global site search results for individual resources.

The library contains **18 curated resources across five shelves** for assets, audio, game study, professional reference and current Unreal/college reference.

New/highlighted sources include ambientCG, Kenney, Quaternius, Sonniss #GameAudioGDC, noclip.website, Interface In Game, The Level Design Book, Noclip documentaries, GDC Vault, Game Developer postmortems and Game Accessibility Guidelines.

Resource cards now show what the source is best for and a visible licence/reference label. A short licence guide distinguishes CC0, terms-specific downloads and study/reference-only sources.

## Compatibility

- No Supabase/database migration.
- No lesson, tutorial, Designer Studio Build or progress IDs changed.
- v3.35.1 scroll restoration and Designer industry deep dives are retained.
- No AI imagery added.
