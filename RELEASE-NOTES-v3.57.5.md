# UE5 Learning Hub v3.57.5 — What Happened Here? Guided Brief

## Main change
Rebuilt the Level 4 **What Happened Here?** environment / level-design pathway as a much more explicit guided production brief.

## What changed
- Expanded from 8 broad stages to **12 detailed production stages**.
- Each detailed stage now has a numbered **DO THESE ONE AT A TIME — IN THIS ORDER** action list.
- Added clear challenge rules: one small space, BEFORE → EVENT → AFTER, five physical clues, one hero clue, no random prop scatter, blind playtesting.
- Added six story starters for students who are stuck without forcing a single narrative.
- Added game-study cards for What Remains of Edith Finch, Gone Home, The Last of Us and BioShock.
- Added a real-world workshop reference with a local Hub fallback.
- Added a local before/after set-dressing reference from the Hub's existing licensed teaching imagery.
- Strengthened the Unreal workflow: level naming, Outliner folders, Player Start, blockout, activity zones, event layer, clue ladder, player route, lighting, sound, blind testing and final evidence.
- Reworked checks so students must prove each stage works before moving on.

## Files changed
- index.html
- app.js
- level4-specialist.css
- data/level4-specialist-projects.js

No database or backend changes.
