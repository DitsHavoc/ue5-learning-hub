# UE5 Learning Hub v3.5 — Gold-standard content map

All 20 lessons now use the richer teaching format piloted in Branches.

Every lesson includes:

- What it is / why it matters / how to think about it
- Where to find or use the tool/system
- Anatomy: what each important part does
- Runtime/process flow
- Two concrete game/Blueprint examples
- Remember This summary
- Guided Build with **DO THIS / WHY / CHECK**
- Quiz, Stretch and independent Challenge
- Play/Watch analysis
- Homework
- Common problems and good practice
- Main-game integration
- Evidence requirements and reflection prompts
- Multiple visuals (existing reference image where useful + original classroom diagrams)

## Original visual expansion

V3.5 generates **38 new original SVG teaching diagrams** (two for each lesson other than Branches).
Branches retains its three bespoke diagrams from V3.4.
