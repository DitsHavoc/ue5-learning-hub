# Resource Library QA — v3.35.2

## Scope

v3.35.2 promotes the old Designer Studio resource strip into a dedicated `#/resources` reference area and broadens it beyond Unreal-only links.

## Navigation targets

- dedicated `#/resources` route
- direct sidebar entry under **Reference**
- prominent Home landing-page bridge
- prominent Designer Studio bridge near the top of the page
- global site search routes individual resource results to the Resource Library

## Library structure

The page contains **18 curated resources** across **5 shelves**:

1. Build fast — assets, materials and placeholders
2. Sound library
3. Study games — level/UI/design reference
4. Hear the professionals — documentaries, talks and postmortems
5. Engine + college reference

Every resource records:

- title
- category
- source URL
- content type
- licence/reference label
- what it is best used for
- short student-facing guidance

## Licence communication

The page intentionally distinguishes:

- **CC0** — easiest classroom reuse
- **terms apply** — listing/provider-specific conditions must be checked
- **reference / study** — use for analysis, not as a source of game assets to extract or copy

The Hub does not claim that all "free" resources have the same licence.
