# Unreal Learning Path — v3.32.1

## Student route

1. **Building Blocks** — learn a reusable Unreal concept in a few minutes.
2. **Core System Lessons** — understand the larger system and why it works.
3. **Quick Tutorials** — build a specific mechanic with exact steps and values.
4. **Challenges & Projects** — remove support and combine systems independently.

## Anti-overload rule

The Hub contains **47** Building Blocks, but only **13 Core** blocks are suggested early. The remaining **32 Common** and **2 Later** blocks are just-in-time references, not a compulsory pre-course.

## Five shelves

1. **Start Here — Unreal Basics**
2. **Blueprint Basics**
3. **Communication & Data**
4. **Characters & Animation**
5. **World, UI, FX & AI**

The shelves organise retrieval; they are not five courses students must complete.

## Link rule

Programming tutorials explicitly declare the Building Blocks they use. Do not infer these links from loose keyword matching when an explicit mapping is available.

A tutorial should normally surface **1–4** blocks, ordered by what is most useful to the learner for that mechanic.

Examples:

- Sprint → Enhanced Input → Variables → Character Movement
- Struct/Data Table → Structs → Data Tables → Enums
- AI Patrol → NavMesh → AIController/Move To → Blackboard/Behaviour Tree
- Camera Shake → Camera/Spring Arm/Camera Shake → Events

## Building Block format

Each block stays deliberately small:

- 30-second explanation
- when to use it
- one prescriptive proof exercise
- one observable check
- links back into real tutorials/system lessons

The proof exercise must include exact editor navigation when the learner is creating an unfamiliar asset or system.
