02

Units & Transforms

1 Unreal Unit (uu) = 1 cm100 uu = 1 metre
  • Location = where it is.
  • Rotation = which way it faces.
  • Scale = how large it is relative to the original.
  • Use grid/rotation snapping for clean blockouts.
  • Judge human scale from the player character/camera, not only the floating editor camera.
03

The UE5 Build/Test Loop

EDIT→COMPILE→SAVE→PLAY→OBSERVE→CHANGE
  • Compile checks/applies Blueprint graph changes.
  • Save writes the asset/project data.
  • Play proves behaviour in the running game.
  • Stopping Play normally discards temporary runtime state changes.

06

State: Default vs Runtime vs Instance

  • Class Default — starting value in the Blueprint asset.
  • Runtime Value — what the running instance currently holds after Set nodes/gameplay changes.
  • Instance Value — a placed Actor can override Instance Editable properties without creating a new class.
  • Owner — keep state near the thing it describes/uses.

DoorLocked → Door. Health → Character/Health Component. TargetDoor → the controller/switch that needs it.

08

References & Communication

  • Object Reference = this exact Actor/object.
  • Class Reference = this type of object.
  • Instance Editable lets a placed Blueprint choose its target in Details.
  • Is Valid before using a reference that may be None/destroyed.
  • Casting does not find an object. It tests/converts a reference you already have.
Accessed None? First check whether the reference was actually assigned.
09

Functions & Events

  • Function — one named reusable job/calculation; use inputs/outputs for changing data.
  • Custom Event — an execution entry point; useful for event-style/latent flow such as sequences that use Delay.
  • Repeated calculation? Refactor it instead of copying five versions.
  • Hard-coded value repeated? Promote it to meaningful data/variable when appropriate.
10

Collections & Structured Data

ArrayOrdered list. Index starts at 0.
For Each LoopRun the same logic once for every Array item.
SetCollection of unique values.
MapKey → value lookup, e.g. Pistol → 12.
EnumOne named choice/state from a controlled list.
StructGroup related fields describing one thing.
11

Debugging Habit

  1. PREDICT what should happen.
  2. TEST in Play.
  3. OBSERVE what actually happened.
  4. TRACE execution and the values feeding the decision.
  5. CHANGE one justified thing.
  6. RETEST.

Useful first tools: Compile messages, Print String, breakpoints, watching the exact variable/reference you think is wrong.

PBR Material Quick Check

Base ColorSurface colour/albedo.
Roughness0 = smooth/sharp reflections; 1 = rough/diffuse reflections.
MetallicUsually 0 for non-metal, 1 for metal. Not a “shininess” slider.
NormalSmall surface-direction detail without extra geometry.

ambientCG beginner workflow: Color/BaseColor → Base Color, Roughness → Roughness, NormalDX → Normal. 2K is a sensible classroom starting point.

13

Greybox / Level Design

  • Build the space with simple geometry before final art.
  • Test scale with the actual player.
  • Test movement gaps, entrances, camera clearance and route readability.
  • Geometry Brush Additive creates brush space; Subtractive removes brush space.
  • A Subtractive Geometry Brush does not cut a normal Shape/Static Mesh cube.
  • Keep a clean greybox version before materials/lighting/model replacement.

15

If It Doesn't Work — Check This First

Nothing happensIs the Event firing? Follow the white execution wire. Compile. Print a message at the start.
Wrong Branch routePrint/check the data feeding Condition. Read the comparison left → right.
Accessed NoneThe Object Reference is probably unassigned/invalid. Check Details and Is Valid.
Only one Array item changesUse For Each Loop and act on Array Element, not one fixed reference.
Subtractive brush does nothingConfirm you are cutting Additive Geometry Brush space, not a normal Static Mesh Shape.
Material looks giganticFix tiling/UV scale. Downloading an 8K texture does not make the physical pattern smaller.
Graph is copied everywhereLook for a Function, Array, Enum, Struct, reusable Actor class or editable data opportunity.
Still stuckState your prediction, actual result and first thing you traced — then use the Hub guide or ask for help.
