# UE5 Learning Hub v3.57.4 — Literal Programmer Guides

## What changed

The entire three-mission Level 4 programmer pathway has been rewritten to the same literal classroom style used when building games together.

- **Mission 1 — Escape Room: Arrays & Maps**
- **Mission 2 — Stop Hard-Coding: Structs & Data Tables**
- **Mission 3 — Stop Repeating Yourself: Functions & Reusable Logic**

Every build step now tells the student exactly where to work and then gives a numbered click/add/type/connect sequence. The guide no longer relies on summary instructions such as “upgrade the generator” or “create a reusable pickup” without spelling out how.

The rewrite includes exact Blueprint/asset names, node searches, pin connections, typed values, compile/save checkpoints, Play tests and expected results.

## Scale of rewrite

- 3 complete programming missions
- 30 stages
- 150 build steps
- 1,361 numbered actions
- minimum 8 explicit actions in every build step

## UI wording

Programming steps now label the ordered instructions:

**DO THESE ONE AT A TIME — IN THIS EXACT ORDER**

The mission header also tells students that every numbered line should be treated as an action and that they should stop at the expected-result check before continuing.

## Deployment

No database or Supabase migration is required.
