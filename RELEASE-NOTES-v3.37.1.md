# v3.37.1 — Topology Step Mockups

Date: 29 Aug 2026

This is a focused prototype pass on three Build X pages: **Crate**, **Barrel / Canister** and **Sci-fi Wall Panel**.

## What changed

- Added a new **READ THE MESH • BEFORE STEP 1** topology section to the three example pages.
- Added 18 original instructional SVG diagrams, six per build.
- Each Build X step now shows a matching visual inside the straight-through guide.
- The visuals explicitly mark support loops, silhouette edges, chamfer targets, UV seams, pivot placement and deliberately unnecessary geometry.
- Added topology legends and short rules explaining **why each edge exists**.
- Kept the existing real-object reference boards, production briefs, planning prompts, variation challenge, quality gates, professional study and Critique Board handoff.

## Scope

This pass intentionally upgrades only three Build X pages so the teaching pattern can be judged before it is rolled out across all eight builds.
