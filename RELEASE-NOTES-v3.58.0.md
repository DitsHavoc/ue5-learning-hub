# UE5 Learning Hub v3.58.0 — Fight Scene Sound Library

## Level 4 Technical Audio rebuilt

The previous broad sound-library brief has been replaced with one focused sound-design production task: **Fight Scene Sound Library**.

Students now design one 30–45 second fight scene through four audio phases:

1. WORLD — environmental bed and location spot sounds
2. BUILD-UP — footsteps, cloth, handling and tension detail
3. FIGHT — movement, impacts, blocks, falls, debris and variations
4. AFTERMATH — tails, settling detail and the environment returning

### Scope

- One fight scene, one location and one coherent sound palette.
- Approximately 25–35 finished library assets rather than 30–50 unrelated sounds.
- The core library is primarily built from students' own recordings.
- A tutor-supplied / self-recorded / simple animated silent clip can be used; visuals are not assessed.
- Music is optional and cannot replace Foley / SFX / ambience.
- Safe Foley rules are explicit.

### Guided production checkpoints

11 studio-style checkpoints now cover:

- scene / sound-story planning
- cue-sheet spotting
- safe Foley planning
- environmental recording
- build-up recording
- movement / whoosh recording
- impact / contact recording
- three layered hero moments
- editing / naming / catalogue
- final 30–45 second fight mix
- blind testing / revision / packaging

The page uses the same Level 4 **MAKE / FOCUS ON / TECHNICAL SETTINGS / QUALITY CHECK / EVIDENCE / IF IT IS NOT WORKING** structure as Hero Prop, without turning the task into a click-by-click DAW tutorial.

### Professional reference added

Links now include combat / game-audio breakdowns for God of War Ragnarök and The Last of Us, plus current Epic UE5.8 audio-engine and attenuation documentation.
