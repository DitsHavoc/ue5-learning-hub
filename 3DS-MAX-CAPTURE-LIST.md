# 3D Modelling Studio — Current 3ds Max Capture List

These are the highest-value interface screenshots to capture from the college's **actual current 3ds Max installation**. Use a clean default-ish workspace, 1920×1080 where possible, and crop a second tighter version when a button/panel needs to be unmistakable.

1. **Full modelling workspace** — viewport, main toolbar and Command Panel visible.
2. **Create → Standard Primitives → Box** — exact current location and Box parameters.
3. **Modify → Editable Poly** — sub-object hierarchy with Vertex / Edge / Border / Polygon / Element.
4. **Polygon selected in viewport** — clear one-face selection with Polygon mode visible.
5. **Inset controls** — tight crop plus resulting inset face.
6. **Extrude controls** — tight crop plus one clean recessed extrusion.
7. **Edge Ring / Loop / Connect** — selection plus Connect settings/result.
8. **Chamfer** — amount + segments visible, with a simple before/after edge.
9. **Modifier stack** — Box → Edit Poly → Symmetry → Chamfer example.
10. **Symmetry** — mirror gizmo/axis and clean result.
11. **Hierarchy → Pivot → Affect Pivot Only** — current panel and a pivot moved to a corner/hinge.
12. **Unwrap UVW modifier** — modifier selected and Open UV Editor control visible.
13. **UV Editor + checker** — shells plus a clear non-stretched checker result.
14. **Material IDs / simple material setup** — only if this is part of the college Substance handoff.
15. **FBX Export Selected dialog** — college-approved current export preset/settings.
16. **UE5.8 import dialog** — Static Mesh import.
17. **UE5.8 Static Mesh Editor** — imported model verification.

## Capture rule

Each screenshot must answer one of these questions:

- **Where is it?**
- **What should mine look like now?**
- **Is mine built correctly?**

If it answers none of them, it does not belong beside an instruction.
