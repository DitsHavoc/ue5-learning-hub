# 3D Modelling Studio — Current 3ds Max Capture List

These are the highest-value screenshots to capture from the college's **actual installed 3ds Max version**. Use a clean default-ish workspace, 1920×1080 where possible, and capture both a full-context image and a tight crop when a control needs to be unmistakable.

## Stage 1 — Control the software

1. **Full modelling workspace** — viewport, Command Panel, main toolbar, Transform Type-In/status area and Scene Explorer visible.
2. **Create vs Modify tabs** — two tight crops showing the difference clearly.
3. **Move / Rotate / Scale** — toolbar crop with W/E/R tools visible.
4. **Transform Type-In** — absolute vs offset values visible with one selected Box.
5. **Angle Snap Toggle** — toolbar location plus an object at a clean 90° rotation.
6. **Snaps Toggle + Grid and Snap Settings** — Vertex snap enabled only.
7. **Three-box precision stack** — close-up showing exact snapped contact with no gap/intersection.
8. **Create → Standard Primitives → Box** — exact current location and Box parameters.

## Stage 2 — Build clean geometry

9. **F4 Edged Faces comparison** — same simple object shaded vs shaded-with-edges.
10. **Editable Poly** — sub-object hierarchy with Vertex / Edge / Border / Polygon / Element.
11. **Polygon selected in viewport** — one-face selection with Polygon mode visible.
12. **Inset controls** — tight crop plus resulting inset face.
13. **Extrude controls** — tight crop plus one clean extrusion/recess.
14. **Ring vs Loop** — two images on the same cylinder so selection direction is obvious.
15. **Connect controls** — edge Ring selection plus Connect result.
16. **Graphite Modeling ribbon** — current Modeling tab with Loop/Ring/selection tools visible.
17. **Chamfer** — amount + segments visible, with a simple before/after edge.
18. **Chamfer Modifier** — stack location and result on a clean hard-surface object.

## Stage 3 — Work like a modeller

19. **Modifier stack** — Box/Edit Poly/Symmetry/Chamfer or another clean non-destructive example.
20. **Symmetry** — mirror gizmo/axis and clean seam/result.
21. **Shell Modifier** — a flat plank/plane before and after thickness.
22. **Segment-budget comparison** — same-size cylinders at low / sensible / excessive side counts in shaded + edged view.
23. **Border mode** — an intentional opening vs an accidental open border.
24. **Hierarchy → Pivot → Affect Pivot Only** — pivot moved to a useful corner/hinge, with mode clearly shown.
25. **Object Snap on a modular wall** — exact module join.
26. **Plank mini-build sequence** — Connect divisions → tiny Open Chamfer gaps → Shell thickness.
27. **Scene Explorer naming** — clean modular naming such as SM_Wall_400 / SM_Wall_Corner_400 / SM_Floor_400.

## Capture rule

Every screenshot must answer at least one question:

- **Where is it?**
- **What should mine look like now?**
- **Is mine built correctly?**

If it answers none of them, it does not belong beside an instruction.
