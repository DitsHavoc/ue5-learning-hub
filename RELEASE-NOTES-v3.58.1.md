# UE5 Learning Hub v3.58.1 — Sequencer Cinematic: Direct One Moment

## What changed
The Level 4 **Sequencer Cinematic** pathway has been rebuilt to match the clearer, production-led standard used by the other specialist projects.

### New project focus
Students now direct **one 30–45 second cinematic moment** in one contained location rather than trying to make a mini-film.

Core structure:

**ESTABLISH → BUILD → REVEAL → RESOLVE**

The project now targets:
- one location / virtual film set;
- 6–8 purposeful Cine Camera shots;
- at least one animated environmental event;
- a deliberate lighting / lens / focus pass;
- ambience and synchronised sound;
- a 1080p draft, blind test and revision pass;
- a final 1080p render plus portfolio evidence.

### Better scaffolding
Added:
- three clearly defined cinematic types: Reveal, Tension and Change;
- eight scope rules to stop projects becoming too large;
- six usable starting prompts;
- four game references with a specific thing to study in each;
- Hub Sequencer / Cinematics links plus Epic references;
- 12 guided production stages containing 100 numbered actions;
- explicit storyboard, rough-cut, Camera Cuts, animation, timing, lighting, sound, testing and final-render stages.

### Guidance balance
Creative decisions are explained and checked rather than prescribed. Technical steps are explicit where Sequencer setup can block progress, but students still make the directing decisions themselves.

### Visual reliability
The cinematic page now uses existing local Hub images for both the hero and process references, avoiding dependence on an external storyboard hotlink.
