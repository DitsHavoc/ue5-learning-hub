# UE5 Learning Hub v3.28.0 — 3ds Max Teaching Quality Pass

**Build date:** 26 August 2026  
**Database migration required:** No

## Why this release exists

v3.28 does not make the 3D Modelling Studio larger for the sake of it. It makes the existing route **slower, safer and easier to learn** after a full teaching audit using the uploaded *Autodesk 3ds Max 2023 Bible* alongside the current Hub design and current Autodesk documentation.

## Major changes

- The 12 modelling lessons are now grouped into **four visible learning stages**.
- Every lesson now shows **TOOLS YOU MAY USE TODAY** and **LEAVE THESE ALONE FOR NOW**.
- Workspace lesson simplified around five essential modelling areas.
- Transform lesson expanded with:
  - one-axis movement discipline;
  - Transform Type-In;
  - Angle Snap;
  - scale-transform warning;
  - a three-box Object Snap precision drill.
- Editable Poly lesson adds an F4 Edged Faces checkpoint before direct mesh editing.
- Extrude/Inset lesson begins with a disposable five-minute drill before the crate is touched.
- Edge Control lesson adds a Ring/Loop prediction drill on a cylinder.
- Topology Clinic adds a **12 / 24 / 48 side segment-budget comparison**.
- Modular Assets adds a small **plank-strip scaffold** using Connect → tiny Open Chamfer → Shell before the room kit.
- Material handoff explicitly avoids legacy Scanline/Standard-material teaching and stays focused on the game pipeline.

## Build X changes

The previous **Simple Desk / Workstation** build has been replaced with **Simple Game Tyre**.

The new tyre build teaches:
- Tube segment judgement;
- Ring and Connect;
- sidewall profile control;
- simple tread Inset/Extrude;
- Chamfer/Symmetry judgement;
- F4 wireframe verification.

Build X support now visibly fades from **Full guidance** on the crate to an **Independent outcome brief** on the hero prop.
