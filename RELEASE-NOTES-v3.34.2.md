# UE5 Learning Hub v3.34.2 — Classes Quick Access

## Added
- Permanent role-aware Classes shortcut directly under Home in the left navigation.
- Teachers see **Classes**; students see **My Class**.
- New dedicated `#/classes` landing page.
- Teacher class cards show student count, academic year, join code/status and one-click access to the existing class detail page.
- Student class cards provide direct access to Evidence & Progress and Class Projects.
- Students can join another class directly from the new My Class page.
- Home now includes a compact role-aware Classes/My Class shortcut.

## Preserved
- Existing Teacher dashboard and detailed class pages remain unchanged.
- Existing class permissions, RLS, join-code behaviour and v3.34.1 confirmation recovery fix remain unchanged.
- No database migration.
