# UE5 Learning Hub v3.57.0 — Level 4 Specialist Projects

Baseline: v3.56.2 LOCAL ONLY homepage hotfix.

Adds a new **Level 4 Specialist Projects** area. Students choose ONE pathway:

- What Happened Here? — Environment / Level Design
- Visual Development Pack — 2D Art
- Hero Prop — 3D Art
- Build a Game Sound Library — Technical Audio
- Sequencer Cinematic — Cinematics / Animation
- Programming Missions — links into the existing programming task bank

Each specialist page includes:

- a clear outcome
- skills being practised
- real-world / game / process imagery where useful
- theory and professional-reference links
- staged DO THIS → WHY → CHECK → COMMON FIX guidance
- definition of done
- stretch task

The environment and Sequencer pathways deliberately use the existing What Remains of Edith Finch asset library as a production resource, not as a recreation brief.

No database migration. The site remains LOCAL ONLY.
