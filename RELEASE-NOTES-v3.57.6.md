# UE5 Learning Hub v3.57.6 — Visual Development Focus Pass

## Visual Development pathway rebuilt
The Level 4 2D pathway is now **Visual Development — Design One Place**.

The old brief asked for too many different art outcomes at once. This pass narrows the task to one environment/location and teaches the development process explicitly.

### New scope
- ONE location only
- 4 visual keywords + one-sentence brief
- 6-image reference board: 4 real-world + 2 media references
- 6 quick thumbnails
- 2 developed directions
- 3 value tests
- 3 colour keys
- 1 final environment key image
- 2 simple process boards

Character, creature and separate prop sheets are no longer required.

### Teaching flow
Nine detailed stages now use the same literal classroom style as the programmer guides:
- exact Photoshop setup
- what to click / create / name
- what to draw at each stage
- when to stop
- what to test before continuing
- common fixes

### Reference improvements
- production concept-sketch example with local fallback
- real-world workshop reference with local fallback
- professional links to Naughty Dog / GDC visual-development material
- prompts for students who need a starting location

No database changes are required.
