# UE5 Learning Hub v3.27.0 — 3ds Max Book Reference Quality Pass

**Build date:** 26 August 2026  
**Database migration required:** No

## Purpose

This is a quality pass over 3D Modelling Studio using the supplied *Essential Guide to 3ds Max for All Levels* as supporting reference material. The goal was not to reproduce the book or inflate the course. It was to keep only figures and principles that make an existing scaffolded lesson clearer.

## Selected figures

Five local figures were retained:

1. **Page 12 — interface overview**: broad workspace orientation only.
2. **Page 31 — rounded hard-surface wireframe + shaded view**: edge flow and purposeful support geometry.
3. **Page 31 — vehicle wireframe**: purposeful topology density on a more complex form.
4. **Page 35 — subdivision progression**: base mesh versus increasing subdivision density.
5. **Page 61 — checker-pattern UV example**: detecting stretch/distortion before texturing.

All are labelled as **supporting reference / not a click guide**. Exact current interface instructions still defer to current Autodesk documentation and the college-version screenshot capture plan.

## Teaching improvements

Book-backed notes now reinforce:

- interface regions versus memorising icons;
- edge flow and comparing shaded + wireframe views;
- subdivision cost and preserving an editable base;
- topology/retopology as purposeful edge flow while preserving form;
- checker-based UV distortion checking and even texel density;
- descriptive names, logical folders and clean asset handoff.

## Deliberately not used

The pass rejected older Material Editor screenshots, rendering/lighting pages, animation/rigging images, script examples and several older interface captures because they would either be out of scope or more confusing than helpful for the current modelling unit.

## Regression scope

No changes to Supabase schema, authentication, projects, evidence, profile/badges, news or SculptGL data structures.
